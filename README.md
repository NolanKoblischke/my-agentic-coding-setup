# my-agentic-coding-setup

## Skills

- **make-experiment-note** — Writes an experiment note into an Obsidian vault at the end of a long Claude Code data-analysis session, using Obsidian Flavored Markdown. Asks for the vault path if it hasn't been specified.
- **reveal-assumptions** — Surfaces the hidden assumptions and implicit choices Claude made during a task, so you can audit its reasoning mid-task or retrospectively.

## Presentation

`presentation.pdf` is a talk on agentic coding in astronomy, covering tools like Codex and Claude Code.
